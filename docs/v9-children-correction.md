# V9 子ども入力欄と誤入力の修正（2026-10-06）

## 原因

登録済みの子どもの年齢があると有無チェックが disabled になっていた。人数が残っていると、チェックを外しても人数から存在タグを再生成した。さらに、タグを除いても家族・会話の記録から存在を再推定していた。

## 修正

- 子ども専用の枠に「有無・人数」「登録済みの子ども」「1人追加」を分けた。本人の年齢入力は「本人」と明記。その他の家族は子ども枠の外で、家族用ラベルを使う。
- 有無チェックは登録済みの年齢があっても解除可能。解除すると人数入力を空欄・無効化し、「有無・人数を保存」で確定する。
- nullable な `people.children_present` を追加。NULL は従来の推定を維持し、false は明示的な解除として扱う。人物・家族・会話データは削除しない。
- 解除した子どもの年齢は折りたたみ内に保持。チェックを戻して保存すれば再使用できる。解除中は一覧の子ども表示とAI相談文の家族欄から除外する。
- 人物編集で子どもタグを追加・除去した場合も有無を同期。最新のタグ・有無の両方を比較して、競合する編集を上書きしない。
- 暗号化バックアップには解除状態も含め、以前の記録は引き続き保存される。

## 保存設定

`20261006_012_children_presence.sql` を既存Supabaseへ適用する。Nullable列を追加するだけで、既存行を更新・削除せず、閲覧・編集権限を変更しない。
