# V9 趣味イラストの簡素化

## 依頼と範囲

採用済みのシンプルな手描きA案のテイストを、V9の全40種類の趣味イラストに適用する。単純な形と少ない陰影を使い、背景情報を減らして小さな人物カードでも趣味を見分けやすくする。

## 変更

- 全40枚のWebPを差し替え。同じIDを維持して既存の自動選択・手動選択を引き継ぐ。
- 一覧、詳細、イラスト選択の画像URLとアプリ入口の更新番号を変更し、ブラウザの旧画像キャッシュを回避する。
- 保存データやデータベースの変更はなし。現在選択中の趣味イラストは、再読み込み後に新しい絵で表示される。
- 制作記録は [assets/20261005-simple-hobbies.md](../v9-preview/assets/20261005-simple-hobbies.md)。以前の絵の制作記録も残す。

## 確認する項目

- 40枚すべてが960×540pxで読み込め、対応する趣味が判別できる。
- 一覧の小さな絵と横長の表紙で、主要な形が見える。
- スマートフォン幅で一覧・詳細・選択画面を確認し、手動選択した同じ画像が保存後も表示される。
- 既存の画像選択・保存・バックアップなどの自動確認を再実行する。
- GitHub Pagesの公開完了後、V9で新しい画像が読み込まれることを確認する。

## 公開前の確認結果

- 全40枚の有効なWebPと960×540pxの寸法を確認。合計容量は4,137,180 bytesから1,505,148 bytesに縮小。
- 375px幅で一覧・詳細・イラスト選択を確認。40枚すべてがブラウザで正常に読み込まれた。
- テスト用人物で野球の絵を保存し、一覧・詳細が同一の新しい画像URLを使うことを確認。320px幅の詳細も確認。
- 既存のJavaScriptテスト37件とPythonテスト6件が成功。差分の形式チェックも成功。
- 独立した読み取り専用レビューで指摘なし。夕暮れシティの画像は元のまま。
