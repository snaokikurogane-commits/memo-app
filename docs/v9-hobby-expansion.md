# V9 趣味の選択肢追加

## 方針

- 採用済みのイラストと人物一覧・詳細のデザインを維持する。
- 趣味イラストを12種類から40種類へ拡張する。
- 一覧・詳細は代表1枚を使い、分割表示は追加しない。
- 自動表示は登録順で最初に一致したタグを使う。手動選択はタグの変更で切り替えない。
- 新しい画像の追加に伴うデータの書き換えは行わない。

## 選び方

イラスト選択に検索欄を追加。名前、別名、英語の識別名で検索できる。「ペット」は犬・猫・ペットの3候補を表示する。検索用の語と自動判定用のタグを分け、犬・猫が一般の「ペット」タグに誤って優先されないようにする。

## 保存先

`20261005_009_hobby_illustrations.sql` でイラスト識別名の許可を拡張する。既存の許可・写真の検証・利用者権限・ストレージ権限は維持する。新規環境は008の後に009を適用する。
