# V9 C案の実装記録

## 承認済み仕様
人物一覧の絵と人物詳細の表紙を共通にする。既存15テーマ、趣味イラスト12種類、自分の写真、趣味タグからの自動選択に対応。既存人物の画像設定は維持し、新規人物は自動。C案の読みやすい縦配置と深緑の操作色に統一。Supabaseの保存を継続し、写真は非公開領域へ保存。写真は長辺1600px・1MiB以下のJPEG、表示位置と拡大率を設定可能。写真を含む暗号化バックアップv2を作り、読取画面はv1/v2に対応。失敗時に元の写真を失わない。

## 作業と受入条件
1. 画像設定・趣味対応表・写真保存処理：既存設定、複数趣味、手動固定、アップロード失敗、人物書込失敗をテスト。
2. バックアップv2と写真確認画面：暗号化往復、v1読取、写真欠落・破損をテスト。
3. V9画面統合とSupabase追加マイグレーション：画像プレビュー、人物/会話/質問の操作をブラウザで確認。写真権限は既存app_membersに合わせる。
4. 趣味画像12種と夕暮れシティを生成してアプリに配置。
5. 全テスト・スマホ幅の画面確認・コードレビュー後にプレビュー公開。外部スキーマの設定と公開URLの応答も確認。

## インターフェース
people.card_image は null（従来テーマ）または {mode:'auto'|'theme'|'illustration'|'photo',illustrationId?,path?,x?,y?,zoom?}。x/y=0..1、zoom=1..3。テーマは既存card_style/card_tintを利用。写真本体は非公開person-card-photosバケットのperson_id/uuid.jpg。画像アップロード→people保存→未参照の古い画像削除。所属保存の失敗と画像保存成功を区別する。
バックアップpayload.version=2、media=[{path,mime:'image/jpeg',base64}]。写真を保存したpeopleの参照を全件含め、欠けた写真があれば成功扱いにしない。外側の暗号化形式はv1のままAES-GCMを維持。
