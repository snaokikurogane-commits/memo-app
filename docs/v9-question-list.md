# V9「次に聞くこと」の一覧整理

## 反映した内容

- 質問を紙色と細い区切り線の一覧で表示。大きな色付きカードとしおり装飾を外した。
- 「聞いた」は一覧に残し、「編集」「削除」は各行の「…」にまとめた。
- メニューは native details / summary を使い、Escape と外側のクリックで閉じる。
- 編集時の本文・次回目安、権限による操作制限、整理モード、完了と元に戻す処理は引き継いだ。
- 削除確認を取り消した際には、閉じたメニューの中ではなく「…」へフォーカスを戻す。
- スマホ幅でも本文16px、操作領域44px以上を維持した。

## 内容の監査

保存済みの旧データ取り込み項目には、質問だけでなく見出し・人物情報・短い話題メモが含まれていることを確認した。今回の変更は表示と操作の整理であり、既存の本文、未完了状態、保存先を変更しない。

今後の内容整理案は、人物情報、元の話題メモ、質問候補、実際に次に聞きたい質問を区別すること。意味の曖昧な単語を自動で質問文に書き換えたり、見出しや人物情報を質問として自動登録したりしない。移行内容は元の文章を残した下書きで確認してから決定する。

個人名や元のメモを含む監査資料と、趣味イラストの新しい見本はローカルに保存し、この公開リポジトリには含めない。
