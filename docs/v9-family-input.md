# V9：子ども情報とタグ・会話メモの改善（2026-10-06）

## 保存形式

- 子どもの存在・人数は既存の `people.profile_tags` に「子どもあり」「子ども2人」の形式で保存。人数不明でも保存できる。
- 保存直前に最新のタグを読み、JSONBの一致条件で更新。他の画面から変更されたタグを無断で上書きしない。30件の上限を超えると整理を案内する。
- 個別の年齢・誕生日は既存の `family_members`。名前は任意、年齢だけでも保存可能。確認日は自動で記録する。年齢を変更しない編集は以前の年齢・確認日の組を保持する。
- 登録済みの子ども情報、または明示的な子どもタグがある人物は一覧に存在を表示。本文からは推測しない。人数はタグで明示された値を用い、部分的な年齢登録の件数を総人数とみなさない。
- 暗号化バックアップは同じテーブルの全項目を保存するため、人数タグ・年齢・確認日も従来形式のまま含まれる。

## 画面

- 人物一覧・詳細に子ども表示を独立して置く。趣味タグの「＋件数」に隠さない。
- 年齢欄を先に出し、呼び名・生年月日は任意の折りたたみにする。
- 人物と会話に共通のタグ候補・カテゴリ・検索を用意。登録済みタグと自由入力を利用可能。
- 会話メモは本文を主にし、短いまとめは任意の折りたたみにする。既存のまとめは編集時に保持する。
- 子育てのイラストを追加。人数タグにも自動対応し、手動固定も可能。既存画像は変更しない。

## 保存先の準備

`v9-preview/20261006_010_parenting_illustration.sql` は既存の画像検証に `parenting` の識別名を1件追加する。既存の写真検証、閲覧・編集権限、ストレージ権限は変更しない。データ行を削除・変更する処理はない。

公開前に既存Supabaseへ適用し、成功と許可リストの確認を行う。未適用の環境では子育ての手動固定が保存エラーになるため、010を先に適用する。
