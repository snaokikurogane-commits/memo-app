# 本人の誕生日・年齢（V9）

## 目的と範囲

人物編集に通常閉じた「誕生日・年齢（任意）」を置く。入力は2欄のみ。呼び方・出会いなど新たな入力項目は増やさない。本人情報は子ども・家族情報と区別する。

- 誕生日は `5/12` の月日だけ、または `1991/5/12` の生年月日を入力可能。日本語の年月日、ハイフン、全角数字も正規化。
- 生年月日が分かれば正確な年齢を計算し、年齢欄は自動表示。
- 年齢だけなら確認日を自動記録し「推定○歳」。月日が分かれば次の誕生日、分からなければ確認日の周年で推定年齢を更新。
- 月日だけの場合は年齢を推測しない。どちらも空なら未登録。
- 名前の下に年齢・誕生日を表示する。入力の途中や単なる名前変更で、年齢の確認日を毎回更新しない。

## 保存

Supabaseの既存 `people` に任意の `age_info` JSONB欄を追加する。既存行はnull、既存のRLS・アクセス権を継承する。生年月日、月日、確認年齢・確認日の組合せを検証する。古いアプリの編集はこの欄を更新しない。

編集では元のage_infoも比較し、別画面による更新を検出する。未適用環境では従来項目の読み取り・保存を維持し、この任意欄を無効にする。

暗号化バックアップはpeopleの全項目を取得しており、age_infoも同じ形式に含まれる。読取画面に本人の年齢・誕生日を表示。旧バックアップは情報がなければ表示しない。AI相談用文章はプロフィールを含める場合だけ反映する。

## 保存先の適用

公開前に010（子育て画像の識別名）と011（本人年齢の任意欄・検証）を適用し、011末尾の読取確認を実行する。個人データ行の編集・削除は含まない。
